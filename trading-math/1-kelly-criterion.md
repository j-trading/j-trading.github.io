## 凯利公式 (Kelly Criterion) —— 职业交易员的“长寿”底线

在交易市场中，最令人沮丧的不是“没看对行情”，而是“看对了行情，却在黎明前爆仓”。很多开发者转行做交易时，习惯于追求高胜率的算法，却忽略了数学上最致命的陷阱：**资金曲线的覆灭。** 

今天，我们介绍交易界的头号生存法则——**凯利公式**，这也很大程度上能解释**期货/币圈**市场爆仓的原因。

---

### 1. 直觉挑战：胜率 60% 的游戏，你会怎么下注？

假设你开发了一个策略，胜率 $60\%$，赔率 $1:1$（赢了赚 1 块，输了赔 1 块）。你有 100 万本金，你会每笔投多少？

*   **保守派：** 每次投 1 万（1%）。增长太慢，浪费了高胜率。
*   **激进派：** 每次投 50 万（50%）。只要连续亏两次（概率 $16\%$），你就直接腰斩，心态瞬间崩盘。

**凯利公式**给出了这个问题的数学最优解：它能在保证不爆仓的前提下，实现财富增长速度的最大化（**最大数学期望**）。

---

### 2. 公式拆解：下注比例的精密刻度

凯利公式（针对简单赔率版）如下：

$$f^* = \frac{bp - q}{b}$$

*   $f^*$：你应该投入的总资金比例。
*   $b$：**赔率**（盈亏比，即平均每笔盈利 / 平均每笔亏损）。
*   $p$：**胜率**（获利交易笔数 / 总交易笔数）。
*   $q$：**败率**（即 $1 - p$）。

> **逻辑：** 只有当 $bp - q > 0$（即期望值为正）时，公式才会给出正的下注比例。如果期望值为负，凯利公式会告诉你：不要下注。

**案例计算：**
回到刚才 60% 胜率、1:1 赔率的游戏：
$f^* = (1 \times 0.6 - 0.4) / 1 = 0.2$
**结论：** 每次投入本金的 **20%**，是这个游戏下财富增长最快的比例。

### 3. python 实现凯利公式


```python
def kelly_position(win_rate: float, odds: float, half_kelly: bool = True) -> float:
    “””
    根据胜率和赔率，计算凯利公式建议的仓位比例。

    Args:
        win_rate: 胜率（0~1），即获利交易笔数 / 总交易笔数
        odds: 赔率（盈亏比），即平均每笔盈利 / 平均每笔亏损
        half_kelly: 是否使用半凯利（默认 True，降低波动）

    Returns:
        建议投入的资金比例（0~1），若期望值为负则返回 0
    “””
    b = odds
    p = win_rate
    q = 1 - p

    # 凯利公式: f* = (bp - q) / b
    kelly_f = (b * p - q) / b

    if kelly_f <= 0:
        return 0.0  # 期望值为负，不下注

    # 半凯利：保留约 75% 的增长速度，但回撤大幅降低
    return kelly_f * 0.5 if half_kelly else kelly_f


# 使用示例：60% 胜率，赔率 1.5
position = kelly_position(win_rate=0.6, odds=1.5)
print(f”建议仓位比例: {position:.1%}”)  # 输出: 建议仓位比例: 16.7%
```

### 4. 实盘局限：
**为什么凯利公式不是万能的？**
*   **黑天鹅（非正态分布）：** 凯利公式假设你亏损的上限是已知的。但在 A 股或数字货币市场，连续跌停或插针可能导致你的单笔亏损远超预期（即 $b$ 发生了崩塌），此时凯利公式失效。
*   **胜率难以估计** 基于历史数据估算未来胜率，天然存在不确定性。基于我个人过去几年的量化经验，由于市场风格转化，策略过拟合，很难找到稳定高胜率方法。如果你的胜率估算过高，凯利公式会给出一个极具攻击性的仓位，直接导致爆仓。 (参考下面的模拟器)

**应用技巧：**
1.  **半凯利（Half-Kelly）：** 现实中由于数据回测存在偏差，职业交易员通常只使用凯利公式建议比例的一半。这能显著减少回撤（标准差降低 50%），但依然保留了约 75% 的增长速度。
2.  **动态修正：** 凯利值不是静态的。随着你最近 50 笔交易表现的变化，`kelly_f` 应该实时调整。

### 5. 凯利公式的交易模拟器

[网页模拟器](https://j-trading.github.io/trading-math/1-kelly-criterion.html)
* 配置参数(`胜率`,`赔率`, `自定义下注比例`)
* 点击`运行模拟` : 此时模型会基于胜率，随机生成200次交易(**蒙特卡洛法**), 并画出实时净值图
* 生成3条净值曲线: 
    * `Full Kelly`曲线 : 即完全按照凯利公式最大期望收益的比例进行**下注**。公式$$f_{full} = \frac{bp -(1-p)}{b}$$
    * `Half Kelly`曲线 : 使用`Full Kelly`一半的下注额度：$$f_{half}= \frac{f_{full}}{2}$$
    * `自定义`曲线 : 拖动`自定义下注比例`自定义下注比例, 不使用`凯利公式`得到的净值图。很容易看出，仓位太重时，即使胜率很高(比如60%)也很容易归零，**这就从数学上解释了币圈的爆仓原理**

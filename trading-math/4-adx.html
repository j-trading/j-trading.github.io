● +DI ● -DI ● ADX
计算公式
Step 1 — 方向移动 DM
+DM = max( Hight − Hight−1, 0 )
−DM = max( Lowt−1 − Lowt, 0 )
若 +DM > −DM → −DM = 0
若 −DM > +DM → +DM = 0
Step 2 — 真实波幅 TR
TR = max(
  Hight − Lowt,
  |Hight − Closet−1|,
  |Lowt − Closet−1|
)
Step 3 — Wilder 平滑
首次 = Σ(前 N 期) / N
之后 = Prev − Prev/N + 当期值
对 +DM、−DM、TR 分别平滑
Step 4 — 方向指标 DI
+DI = 100 × Smoothed(+DM) / Smoothed(TR)
−DI = 100 × Smoothed(−DM) / Smoothed(TR)
Step 5 — 趋向指数 DX
DX = 100 × |+DI − −DI| / (+DI + −DI)
Step 6 — 平均趋向指数 ADX
首次 ADX = Σ(前 N 期 DX) / N
之后 ADX = (Prev×(N−1) + DX) / N
读数指南
ADX > 25：趋势强劲（上升或下降）
ADX < 20：市场盘整，无明确趋势
+DI > −DI：多头方向占优
−DI > +DI：空头方向占优
ADX 上升：趋势正在增强
